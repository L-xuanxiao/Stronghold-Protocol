这是完整离线 Android APK 的候选版本，包含作者原版游戏、素材与手机内置 Node 运行时。

请在正式发布前完成真机验收：首次离线启动及完整单人对局、设置/干员调配覆盖升级、双设备局域网联机、房主后台与锁屏、Doze 和网络切换。当前对局不做跨进程存档，系统强停会结束对局。
