本次 Android 版同步作者 **v0.3.0**，包含上一正式 Android 版 v0.2.6 之后的更新；原计划 v0.2.7 的部分修复也已合并到本版。游戏、美术、音频和官方特效素材随 APK 提供，支持手机独立离线单机和主动开启局域网联机。适用于 **ARM64 / Android 7.0 及以上**。

### 上游游戏更新

以下整理自作者 [v0.3.0 正式说明](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.3.0)。

- **插件系统与工作台**：上游新增外观、数据、DSL 和脚本插件，以及 `/studio/` 浏览器工作台，可使用模板、预览和对照试跑；玩法插件房间标记为「非官方」。脚本默认关闭。Android 内嵌 WebView 的插件导入/导出、脚本沙箱及插件跨升级保留尚未专项验证。
- **官方战斗特效**：设置新增关闭、精简、完整三档官方特效，手机默认精简；涵盖普攻、弹道、命中、部署及大量技能特效。特效素材与索引均随 APK 提供；不支持 WebGL2 或使用 2D 棋盘时保留原有表现。
- **场景与统计页**：重新提取 11 个战场场景，改善光照、反射、高光、法线和水面；统计页增加称号、成就、单局纪录及常用盟约/策略等展示。
- **更多语音语言**：新增英语、韩语及部分干员本土语言，可在设置切换，也可为干员单独选择配音并试听；完整配音资源已打包。
- **规则与 AI 修复**：改善机器人站位、采购与布阵；修正攻击追踪判定、木驮兽等载客机制、自制投石机三连击、冻结商店刷新及多项干员/装备交互。

完整条目及插件限制见作者 [v0.3.0 更新说明](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.3.0)和 [CHANGELOG](https://github.com/sganggs/Stronghold-Protocol/blob/v0.3.0/CHANGELOG.md)。感谢原作者与上游贡献者。

### Android 修复与安装

- 修复新版资源数量增长导致首次离线启动失败的问题，同时扩大有界清单容量并统一清单/ZIP 文件数限制；继续校验文件哈希、路径、符号链接及资源完整性。
- 补齐 `data/local-fx.json` 官方特效索引及其素材引用校验，避免只打入素材而遗漏索引。
- 补齐 v0.3.0 服务器直接依赖的素材解析器，修复首次启动时提示 `Cannot find module .../tools/assets/skel.mjs` 的问题。
- 下载 **Stronghold-Protocol-0.3.0-arm64-v8a.apk**，结束当前对局后直接覆盖安装。包名及长期签名保持一致；请保留应用数据，并提前导出设置和干员调配备份。该备份入口不保证覆盖新增插件数据。
- 资源较上一版明显增大，APK 为 **1,214,801,590 bytes（约 1.21 GB / 1.13 GiB）**；安装后首次启动建议保留至少 **3 GB** 可用空间，下载和安装 APK 另需空间。
- 文件名和安装界面版本文字显示 **0.3.0**，内部递增序号仅用于覆盖升级。
- 按维护者要求不运行上游全量游戏测试，保留移动打包、Android 构建/单元/lint、16 KB 离线启动与签名检查。

### 验证范围与自动检查

本轮两种 APK 构建、Android 单元 18 项、lint、实际 16 KB 模拟器首次断网清数据启动、进入大厅、WebSocket 和界面重建均已通过；移动工具 23 项通过，1 个无缓存探针跳过，后续实际 Gradle 构建成功。31,610 项素材引用无缺失，正式发布另核对长期签名与 APK 摘要。本版不追加真机测试；完整对局、特效/语音真机表现、插件工作流、正式签名覆盖升级、双设备、Doze、网络切换及 Android 7.0 / 低内存设备兼容性仍待验证。当前对局没有跨进程存档，系统强停会结束对局。详见 [验证记录](https://github.com/L-xuanxiao/Stronghold-Protocol/blob/codex/android/mobile/VALIDATION.md)。

检查计划保持北京时间每天 **06:00、18:00**。本版因 GitHub 定时未触发而由维护者手动补跑；工作流与 Actions 均启用，公开 API 无法确认本次漏触发的具体平台原因。后续调度恢复仍待观察，GitHub 定时不保证准点或必达；手机仍需手动下载新版 APK。

公开附件仅提供 APK，GitHub 显示附件 SHA256。游戏源码锁定为 [v0.3.0 / c24e17e](https://github.com/sganggs/Stronghold-Protocol/tree/c24e17eec3af1e6dedfa9935a6d15245cf2f4586)，Android 适配源码和锁文件见 [本次 Release 标签](https://github.com/L-xuanxiao/Stronghold-Protocol/tree/android-v0.3.0-100030/mobile)。完整源码、锁文件、运行时输入和签名记录保留在维护者的构建备份草稿；正式发布使用通过验证的同一份候选 APK，保留上一稳定版。
